    <h2>Software Defined Radio References</h2>
<ul>
<li>Passive radar tutorial using dual RTL-SDR dongles: <a href="https://www.rtl-sdr.com/a-fm-radio-passive-radar-system-from-two-rtl-sdr-dongles/">https://www.rtl-sdr.com/a-fm-radio-passive-radar-system-from-two-rtl-sdr-dongles/</a></li>
<li>GitHub implementation (<code>passiveRadar</code>): <a href="https://github.com/Max-Manning/passiveRadar">https://github.com/Max-Manning/passiveRadar</a></li>
<li>Recommended hardware: <em>RTL-SDR Blog V3 R860 RTL2832U 1PPM TCXO SMA Software Defined Radio</em> — <a href="https://a.co/d/9PiepSK">https://a.co/d/9PiepSK</a>. The V3 includes an aluminium enclosure, passive cooling, and supports direct sampling for HF (with reduced performance).</li>
<li>Note: the V3 can be modified to share a reference clock for phase-coherent setups.</li>
</ul>
<h2>Broadcast Frequency Cheat Sheet</h2>
<p>TV channel assignments span 54–806 MHz, divided into 68 channels, each 6 MHz wide. To derive the picture carrier for a channel, add <strong>1.25 MHz</strong> to the lower bound of its frequency range.</p>
