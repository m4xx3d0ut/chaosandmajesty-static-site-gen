  18. <h1>Passive Radar</h1>
  19. <p><a href="https://www.rtl-sdr.com/a-fm-radio-passive-radar-system-from-two-rtl-sdr-dongles/">https://www.rtl-sdr.com/a-fm-radio-passive-radar-system-from-two-rtl-sdr-dongles/</a></p>
  20. <p><a href="https://github.com/Max-Manning/passiveRadar">https://github.com/Max-Manning/passiveRadar</a></p>
  21. <p>RTL-SDR Blog V3 R860 RTL2832U 1PPM TCXO SMA Software Defined Radio (Dongle Only) (Black) <a href="https://a.co/d/9PiepSK">https://a.co/d/9PiepSK</a></p>
  22. <p>This is an RTL-SDR blog V3 software defined radio receiver with RTL2832U ADC chip, R860 tuner, 1PPM TCXO, SMA F connector and aluminium case with passive cooling. Tunes from 500 kHz to 1.7 GHz with up to 3.2 MHz (2.4 MHz stable) of bandwidth. (HF works in direct sampling mode with reduced performance).</p>
  23. <p>Can be modified to share clock for phase coherence.</p>
  24. <h2>Frequency</h2>
  25. <p>TV channel frequencies are assigned in 54 to 806 MHz RF frequency band. These total spectrum is divided into 68 TV channels. Each channel occupies 6MHz bandwidth. To calculate picture carrier value, add 1.25MHz to the lower frequency range.</p>
  26. <p>The FM broadcast in the United States starts at 88.0 MHz and ends at 108.0 MHz. The band is divided into 100 channels, each 200 kHz (0.2 MHz) wide.</p>
  27. <p>The transponder receives interrogation from the Secondary Surveillance Radar on 1030 MHz and replies on 1090 MHz.</p>
