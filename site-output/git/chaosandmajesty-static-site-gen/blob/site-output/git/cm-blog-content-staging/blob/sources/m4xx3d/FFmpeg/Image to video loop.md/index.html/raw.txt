<p>Resize image as needed:</p>
<pre><code class="language-bash">convert EoE.png -resize 1920x1080 UCI-TCL_EoE.png
</code></pre>
<p>To create a 10 minute, 30 FPS, video loop from a single input image:</p>
<pre><code class="language-bash">ffmpeg -loop 1 -i input.png -t 600 -r 30 -pix_fmt yuv420p output.mp4
</code></pre>
