  10. To convert a 4K MOV video to a 1920x1080 H.264 AAC MP4 using FFmpeg, you can use the following command:
  11. ​
  12. ```bash
  13. ffmpeg -i input.mov -vf "scale=1920:1080" -c:v libx264 -crf 23 -c:a aac -b:a 192k output.mp4
  14. ```
  15. ​
  16. Let's break down the command:
  17. ​
  18. - `-i input.mov` specifies the input file, in this case, `input.mov`.
  19. - `-vf "scale=1920:1080"` sets the output video resolution to 1920x1080 by scaling it.
  20. - `-c:v libx264` sets the video codec to H.264, which is widely supported.
  21. - `-crf 23` sets the video quality. Lower values result in higher quality but larger file size. Reasonable values range from 18 to 28.
  22. - `-c:a aac` sets the audio codec to AAC, a commonly used audio format.
  23. - `-b:a 192k` sets the audio bitrate to 192 kbps.
  24. - `output.mp4` specifies the output file name, in this case, `output.mp4`.
  25. ​
  26. Make sure you have FFmpeg installed and properly set up in your system before running this command.
  27. ​
  28. ---
  29. ​
  30. To utilize NVIDIA NVENC for hardware-accelerated video encoding and convert a 4K MOV video to a 1920x1080 H.264 AAC MP4 with the output format set to YUV420p, you can use the following FFmpeg command:
  31. ​
  32. ```bash
  33. ffmpeg -i input.mov -vf "scale=1920:1080" -c:v h264_nvenc -rc:v vbr_hq -b:v 8M -pix_fmt yuv420p -c:a aac -b:a 192k output.mp4
  34. ```
  35. ​
  36. Here's an explanation of the additional options used in the command:
  37. ​
  38. - `-c:v h264_nvenc` specifies the video codec as NVIDIA NVENC H.264 encoder.
  39. - `-rc:v vbr_hq` sets the rate control mode to variable bitrate with high quality.
  40. - `-b:v 8M` sets the target video bitrate to 8 Mbps. You can adjust this value as needed.
  41. - `-pix_fmt yuv420p` specifies the pixel format as YUV420p, which is commonly used and widely supported.
  42. - The remaining options for audio encoding remain the same as in the previous command.
  43. ​
  44. Remember to have FFmpeg with NVIDIA NVENC support installed and properly configured on your system for this command to work.
