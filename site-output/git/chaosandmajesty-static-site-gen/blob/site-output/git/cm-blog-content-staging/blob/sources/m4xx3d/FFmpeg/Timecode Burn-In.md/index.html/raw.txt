<h3>TC Bottom Center</h3>
<p>To overlay time code on an MP4 video using ffmpeg from the Linux command line, you can use the drawtext filter. Here&#39;s an example command:</p>
<pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2&quot; -c:a copy output.mp4
</code></pre>
<p>Let&#39;s break down the command:</p>
<ul>
<li><code>-i input.mp4</code>: Specifies the input video file.</li>
<li><code>-vf &quot;drawtext=fontfile=/path/to/font.ttf:text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2&quot;</code>: Applies the drawtext filter to overlay the time code on the video. Here&#39;s what each parameter does:<ul>
<li><code>fontfile</code>: Specifies the path to the font file you want to use. Replace <code>/path/to/font.ttf</code> with the actual path to your font file.</li>
<li><code>text</code>: Sets the text to be displayed. <code>%{pts\:hms}</code> is a special variable that represents the current time in hours:minutes:seconds format.</li>
<li><code>x</code> and <code>y</code>: Specify the position of the text on the video. <code>(w-tw)/2</code> centers the text horizontally, and <code>h-th-10</code> positions it 10 pixels from the bottom.</li>
<li><code>fontsize</code>: Sets the font size of the text (e.g., 24).</li>
<li><code>fontcolor</code>: Specifies the font color (e.g., white).</li>
<li><code>bordercolor</code> and <code>borderw</code>: Sets the color and width of the text border (e.g., black and 2 pixels).</li>
</ul>
</li>
<li><code>-c:a copy</code>: Copies the audio stream from the input to the output without re-encoding.</li>
<li><code>output.mp4</code>: Specifies the output video file.</li>
</ul>
<p>Make sure to replace <code>input.mp4</code> with the path to your actual input video file, and <code>output.mp4</code> with the desired name/path for the output file. Additionally, replace <code>/path/to/font.ttf</code> with the path to the font file you want to use for the time code overlay.<strong>strong text</strong></p>

<h3>TC Centered in Frame</h3>
<p>To overlay time code with a font size of 48 on the center of the frame in an MP4 video using ffmpeg, you can use the following command:</p>
<pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:fontsize=48:fontcolor=white:box=1:boxcolor=black@0.5:boxborderw=5:text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=(h/PHI)+th&quot; -codec:a copy output.mp4
</code></pre>
<p>Here&#39;s a breakdown of the command:</p>
<ul>
<li><code>-i input.mp4</code> specifies the input video file.</li>
<li><code>-vf</code> is the video filter option used to apply the drawtext filter.</li>
<li><code>drawtext</code> is the filter that allows drawing text on the video frames.</li>
<li><code>fontfile=/path/to/font.ttf</code> sets the path to the font file you want to use. Replace <code>/path/to/font.ttf</code> with the actual path to the font file you want to use. Make sure to provide the correct path to the font file.</li>
<li><code>fontsize=48</code> sets the font size to 48.</li>
<li><code>box=1:boxcolor=black@0.5:boxborderw=5</code> adds a black semi-transparent box behind the text for better visibility. You can adjust the box color, transparency (0.5 in this example), and border width (5 in this example) as per your preference.</li>
<li><code>text=&#39;%{pts\:hms}&#39;</code> sets the text to be displayed as the time code in the format hours:minutes:seconds.</li>
<li><code>x=(w-tw)/2:y=(h/PHI)+th</code> calculates the position of the text overlay to be centered on the frame. <code>x</code> determines the horizontal position, and <code>(w-tw)/2</code> ensures it is centered. <code>y</code> determines the vertical position, and <code>(h/PHI)+th</code> places it slightly above the center. You can adjust the vertical and horizontal positions based on your requirements.</li>
<li><code>-codec:a copy</code> copies the audio stream from the input to the output without re-encoding, ensuring there is no loss in audio quality.</li>
<li><code>output.mp4</code> is the output video file.</li>
</ul>
<p>Make sure to replace <code>input.mp4</code> with the path to your input video file and <code>output.mp4</code> with the desired output file name and extension.</p>
