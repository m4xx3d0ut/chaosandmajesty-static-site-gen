## Grep

In the `grep` command, you can use regular expressions to find patterns with wildcards. The wildcard symbol in regular expressions is `.` (dot), which matches any character. To match zero or more occurrences of the previous character or expression, you can use `*`. So, to find the pattern "OS" followed by any characters within curly braces, you can use the following `grep` command:

```bash
grep 'OS{.*}' your_file.txt
```

In this command:

- `grep` is the command for searching patterns in files.
- `'OS{.*}'` is the regular expression pattern you're looking for. Here, `OS` matches the characters "OS", `{` and `}` match themselves, and `.*` matches any sequence of characters (the dot `.` is a wildcard, and `*` means zero or more occurrences).
- `your_file.txt` is the name of the file you want to search in. Replace it with the actual filename.

Please note that curly braces `{}` are usually used for specifying repetition in regular expressions, so if you want to literally match curly braces, you might need to escape them with backslashes like this:

```bash
grep 'OS\{.*\}' your_file.txt
```

Remember that `grep` uses basic regular expressions by default. If you're dealing with more complex patterns, you might need to use extended regular expressions by using the `-E` option:

```bash
grep -E 'OS\{.*\}' your_file.txt
```

In Bash, you can split a string on the last occurrence of the forward slash ("/") and retrieve the last element (file or directory name) by using parameter expansion. Here's how you can do it:

```bash
path="/path/to/your/directory/file.txt"
# Use parameter expansion to split on the last "/"
last_element="${path##*/}"
echo "Last element: $last_element"
```

If you want to iterate through all files in the current working directory (`pwd`), you can do so with the following one-liner:

```bash
for file in "$(pwd)"/*; do [ -f "$file" ] && echo "Processing file: $file"; done
```

To iterate through all files in a directory using a Bash script, you can use a `for` loop and the `*` wildcard to match all files in the directory. Here's a basic example of how to do this:

```bash
#!/bin/bash

# Specify the directory you want to iterate through
directory="/path/to/your/directory"

# Use a for loop to iterate through the files
for file in "$directory"/*; do
    if [ -f "$file" ]; then
        echo "Processing file: $file"
        # You can perform operations on "$file" here
    fi
done
```

## Find and Replace String Recursively

Command breakdown

grep -r: --recursive, recursively read all files under each directory.
grep -l: --print-with-matches, prints the name of each file that has a match, instead of printing matching lines.
grep -i: --ignore-case.

xargs: transform the STDIN to arguments.
xargs -i@ ~command contains @~: a placeholder for the argument to be used in a specific position in the ~command~, the @ sign is a placeholder which could replaced by any string.

sed -i: edit files in place, without backups.
sed s/regexp/replacement/: substitute string matching regexp with replacement.
sed s/regexp/replacement/g: global, make the substitution for each match instead of only the first match.

```
grep -rli 'old-word' * | xargs -i@ sed -i 's/old-word/new-word/g' @
```
