  274. <h3>Preparing the Attack</h3>
  275. <p>Important considerations when using malicious Office Doc in a client-side attack.</p>
  276. <ul>
  277. <li>Delivery method<ul>
  278. <li>Macro attacks are well known, email provider spam filters often filter out all MS Office Docs<ul>
  279. <li>In most cases we can&#39;t just send it as an email attachment</li>
  280. </ul>
  281. </li>
  282. <li>Most anti-phishing training programs stress the danger of enabling macros in an emailed Office Doc</li>
  283. </ul>
  284. </li>
  285. </ul>
  286. <p>To deliver the Doc and increase the chance of target opening it, we have to use a convincing pretext and an alternate delivery method. A download link for example.</p>
  287. <p>If succesfully delivered and opened, the doc will be tagged with the <a href="https://attack.mitre.org/techniques/T1553/005/">&quot;Mark of the Web&quot; (MOTW)</a>. An Office doc tagged with MOTW will open in a <a href="https://support.office.com/en-us/article/what-is-protected-view-d6f09ac7-e6b9-4495-8e43-2bbcdbcb6653">protected view</a> which disabled editing and blocks the execution of macros or embedded objects. When a target opens a MOTW Doc, they see a warning with the option to Enable Editing.</p>
  288. <p>When the target enables editing, the protected view is disabled. The most direct way to bypass MOTW is to convince the target to click Enable Editing.</p>
  289. <ul>
  290. <li>Example;<ul>
  291. <li>Blur the body of the doc and intruct the target to click the Enable Editing button to view it.</li>
  292. </ul>
  293. </li>
  294. </ul>
  295. <p>Not all Office docs have a protected view, Microsoft Publisher does not but is less frequently present on a system.</p>
  296. <p>Microsoft also announced blocking macros by default. Affecting Access, Excel, PowerPoint, Visio, and Word in most Office versions from 2013-2021. Dates can be found in <a href="https://learn.microsoft.com/en-us/deployoffice/security/internet-macros-blocked">MS Learn page</a>.</p>
  297. <p>The Enable Content button is no longer available for Office docs delivered from the internet. A more tedious process of following a link outlining the dangers, following instructions, and checking a box in settings. This complicated the vector, but with thorough enumeration and considering the information here the chance of success increases greatly.</p>
  298. <p>Despite the mitigation and heightened awareness, malicious Office Docs are still one of the most widely used client-side attack vectors. This highlights the dynamic between attacker and defender. For each security measure implemented the attacker is forced to develop a novel vectors and bypass methods. New defense mechanisms are just opportunities to develop more sophisticated attacks.</p>
  299. <h3>Leveraging Microsoft Word Macros</h3>

  490. <h4>Attaining Code Execution via Windows Library Files</h4>
  491. <p>Win Library files are virtual containers that connect users with content stored in remote locations;</p>

  493. <li>web servers</li>

  495. <li>they have a <code>.Library-ms</code> file extension</li>

  498. <p>We will explore a 2 stage client-side attack;</p>
