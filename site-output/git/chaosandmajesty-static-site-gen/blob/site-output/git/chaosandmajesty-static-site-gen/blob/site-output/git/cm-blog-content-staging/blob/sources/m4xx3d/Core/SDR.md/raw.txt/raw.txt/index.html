  12. RTL-SDR Blog V3 R860 RTL2832U 1PPM TCXO SMA Software Defined Radio (Dongle Only) (Black) https://a.co/d/9PiepSK
  13. ​
  14. This is an RTL-SDR blog V3 software defined radio receiver with RTL2832U ADC chip, R860 tuner, 1PPM TCXO, SMA F connector and aluminium case with passive cooling. Tunes from 500 kHz to 1.7 GHz with up to 3.2 MHz (2.4 MHz stable) of bandwidth. (HF works in direct sampling mode with reduced performance).
  15. ​
  16. Can be modified to share clock for phase coherence.
  17. ​
  18. ## Frequency
  19. ​
  20. TV channel frequencies are assigned in 54 to 806 MHz RF frequency band. These total spectrum is divided into 68 TV channels. Each channel occupies 6MHz bandwidth. To calculate picture carrier value, add 1.25MHz to the lower frequency range.
  21. ​
  22. The FM broadcast in the United States starts at 88.0 MHz and ends at 108.0 MHz. The band is divided into 100 channels, each 200 kHz (0.2 MHz) wide.
  23. ​
  24. The transponder receives interrogation from the Secondary Surveillance Radar on 1030 MHz and replies on 1090 MHz.
