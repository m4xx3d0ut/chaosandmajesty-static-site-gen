  25. <div class="blog-article-content">
  26. <ul>
  27. <li>Use <code>-ss</code>/<code>-t</code> with <code>-c copy</code> to clip segments without re-encoding, and rely on <code>libx264</code>/<code>libx265</code> (or <code>h264_nvenc</code>) when you need transcodes.</li>
  28. <li>Loop still images or test patterns with <code>-loop 1</code> and <code>lavfi</code> sources, then concat segments via a manifest to reach longer runtimes.</li>
  29. <li>The <code>drawtext</code> filter handles timecode overlays; remember to point to a valid font and position text with expressions like <code>(w-tw)/2</code>.</li>
  30. </ul>
  31. <h2>Working Notes... In Graphic Detail...</h2>
  32. <h3>Transcode 4K MOV to 1080p H.264 AAC</h3>
  33. <pre><code class="language-bash">ffmpeg -i input.mov -vf &quot;scale=1920:1080&quot; -c:v libx264 -crf 23 -c:a aac -b:a 192k output.mp4
  34. </code></pre>
  35. <p>Hardware-accelerated NVENC variant:</p>
  36. <pre><code class="language-bash">ffmpeg -i input.mov -vf &quot;scale=1920:1080&quot; -c:v h264_nvenc -rc:v vbr_hq -b:v 8M -pix_fmt yuv420p -c:a aac -b:a 192k output.mp4
  37. </code></pre>
  38. <p>Reduce file size with HEVC:</p>
  39. <pre><code class="language-bash">ffmpeg -i input.mp4 -c:v libx265 -crf 28 -c:a copy output.mp4
  40. </code></pre>
  41. <p>Batch transcode current directory to an <code>out/</code> folder:</p>
  42. <pre><code class="language-bash">mkdir -p out
  43. for file in &quot;$(pwd)&quot;/*; do
  44. [ -f &quot;$file&quot; ] || continue
  45. ffmpeg -y -i &quot;$file&quot; -c:v libx264 -crf 28 -c:a copy &quot;$(pwd)&quot;/out/&quot;${file##*/}&quot;
  46. done
  47. </code></pre>
  48. <h3>Clip a Segment</h3>
  49. <pre><code class="language-bash">ffmpeg -ss 00:00:00 -t 00:00:20 -i input.mp4 -c copy output.mp4
  50. </code></pre>
  51. <h3>1-Minute SCTE Test Pattern (MJPEG)</h3>
  52. <pre><code class="language-bash">ffmpeg -f lavfi -i testsrc=size=1920x1080:rate=30 -t 60 -c:v mjpeg -an output_test_pattern.mjpeg
  53. </code></pre>
  54. <h3>1 kHz Audio Tone (60 seconds)</h3>
  55. <pre><code class="language-bash">ffmpeg -f lavfi -i sine=frequency=1000:duration=60 -c:a pcm_s16le audio.wav
  56. </code></pre>
  57. <h3>Bouncing Ball Test Pattern (excerpt)</h3>
  58. <p>Generate a five-minute MJPEG test clip with moving graphics:</p>
  59. <pre><code class="language-bash">ffmpeg -f lavfi -i &quot;testsrc=size=1920x1080:rate=30&quot; \
  60. -f lavfi -i &quot;life=s=1920x1080:mold=10:r=30:ratio=0.1:death_color=black:life_color=white&quot; \
  61. -filter_complex &quot;overlay&quot; -t 300 -c:v mjpeg -an bouncing-ball.mjpeg
  62. </code></pre>
  63. <h3>Loop a Single Image</h3>
  64. <p>Resize as needed (ImageMagick):</p>
  65. <pre><code class="language-bash">convert input.png -resize 1920x1080 frame.png
  66. </code></pre>
  67. <p>Build a 10-minute, 30 FPS loop:</p>
  68. <pre><code class="language-bash">ffmpeg -loop 1 -i frame.png -t 600 -r 30 -pix_fmt yuv420p loop-10min.mp4
  69. </code></pre>
  70. <p>Concatenate six loops into an hour-long clip:</p>
  71. <pre><code class="language-bash">for i in {1..6}; do echo &quot;file &#39;loop-10min.mp4&#39;&quot; &gt;&gt; concat.lst; done
  72. ffmpeg -f concat -safe 0 -i concat.lst -c copy loop-60min.mp4
  73. </code></pre>
  74. <h3>Burn-In Timecode</h3>
  75. <p>Top-left overlay (adjust font path):</p>
  76. <pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:fontsize=32:fontcolor=white:\
  77. box=1:boxcolor=black@0.5:boxborderw=5:text=&#39;%{pts\:hms}&#39;:x=20:y=20&quot; -c:a copy output.mp4
  78. </code></pre>
  79. <p>Centered overlay with golden-ratio offset:</p>
  80. <pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:fontsize=48:fontcolor=white:\
  81. box=1:boxcolor=black@0.5:boxborderw=5:text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=(h/PHI)+th&quot; -c:a copy output.mp4
  82. </code></pre>
  83. <p>Sample grabbing from an HLS stream and exporting a 20-second clip with timecode:</p>
  84. <pre><code class="language-bash">ffmpeg -ss 00:04:30 -t 20 -i https://example.com/endpoint/index.m3u8 \
  85. -vf &quot;drawtext=fontsize=48:fontcolor=white:box=1:boxcolor=black@0.5:boxborderw=5:\
  86. text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=(h/PHI)+th&quot; -c:a copy clip-with-tc.mp4
  87. </code></pre>
  88. <h3>Quick Reference Commands</h3>
  89. <ul>
  90. <li>Create an MJPEG video test card and matching sine-wave audio tone for end-to-end testing.</li>
  91. <li>Loop a still image via <code>-loop 1</code> and use the concat demuxer to extend the runtime.</li>
  92. <li>Clip segments with <code>-ss</code>/<code>-t</code>, preserving audio with <code>-c:a copy</code>.</li>
  93. <li>Switch between software (<code>libx264</code>, <code>libx265</code>) and hardware (<code>h264_nvenc</code>) encoders depending on the workstation.</li>
  94. </ul>
