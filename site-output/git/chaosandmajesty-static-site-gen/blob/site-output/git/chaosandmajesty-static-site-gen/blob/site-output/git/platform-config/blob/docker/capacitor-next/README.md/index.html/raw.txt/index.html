  881. <h2>2) Remove the secret from your Pod env entirely (more secure)</h2>
  882. <p>Since the app doesn’t use those creds, stop injecting them into the container:</p>
  883. <pre><code class="language-diff"># gitops/apps/capacitor-next/deploy.yaml
  884. @@
  885. containers:
  886. - name: app
  887. @@
  888. - envFrom:
  889. - - secretRef:
  890. - name: capacitor-next-auth
  891. </code></pre>
  892. <p>(Leaving the env var there is harmless functionally, but it leaks your htpasswd into the pod’s environment for no reason.)</p>
  893. <h2>3) Add NGINX Ingress basic-auth annotations</h2>
  894. <p>This is why you “don’t see a basic auth flow”: your <code>Ingress</code> doesn’t reference the secret yet.</p>
  895. <pre><code class="language-yaml"># gitops/apps/capacitor-next/ingress.yaml
  896. apiVersion: networking.k8s.io/v1
  897. kind: Ingress
  898. metadata:
  899. name: capacitor-next
  900. namespace: flux-system
  901. annotations:
  902. nginx.ingress.kubernetes.io/auth-type: basic
  903. nginx.ingress.kubernetes.io/auth-secret: capacitor-next-auth
  904. nginx.ingress.kubernetes.io/auth-realm: &#39;Authentication Required&#39;
  905. spec:
  906. rules:
  907. - host: &lt;your.host&gt;
  908. http:
  909. paths:
  910. - path: /
  911. pathType: Prefix
  912. backend:
  913. service:
  914. name: capacitor-next
  915. port:
  916. number: 3333
  917. </code></pre>
  918. <h2>Sanity checks</h2>
  919. <ul>
  920. <li><p>Verify the secret has only the <code>auth</code> key (and that it decodes to htpasswd):</p>
  921. <pre><code class="language-bash">kubectl -n flux-system get secret capacitor-next-auth -o jsonpath=&#39;{.data}&#39; | jq .
  922. kubectl -n flux-system get secret capacitor-next-auth -o jsonpath=&#39;{.data.auth}&#39; | base64 -d
  923. </code></pre>
  924. </li>
  925. <li><p>Commit &amp; let Flux reconcile:</p>
  926. <pre><code class="language-bash">git add .
  927. git commit -m &quot;capacitor-next: use Ingress basic auth; drop unused secret keys; stop env injection&quot;
  928. git push
  929. flux reconcile kustomization apps -n flux-system
  930. </code></pre>
  931. </li>
  932. <li><p>Hit the host—browser should now prompt for Basic Auth.</p>
  933. </li>
  934. </ul>
  935. <p>If you prefer to keep <code>envFrom</code> for later, you still <strong>should</strong> rename the secret keys you don’t want injected; but the cleaner pattern is to remove <code>envFrom</code> entirely when credentials are only for Ingress.</p>
