Before you ship, make sure to:

- ✅ Update the site title, description, and meta keywords inside your YAML file.
- ✅ Replace the demo social preview image under `assets/static/img/`.
- ✅ Review the generated HTML in `site-output/` and ensure accessibility checks pass.
- ✅ Mirror your git repositories (optional) using the stagit instructions in the docs.

Once everything looks good, rebuild the site and deploy the `site-output/` directory via your preferred platform.
