        <h1>DOOM WASM Assets</h1>
<p>This folder stores the <code>doom.wasm</code> binary and browser loader consumed by the
console minigame.</p>
<h2>Provenance</h2>
<ul>
<li>Upstream source: <a href="https://github.com/diekmann/wasm-fizzbuzz"><code>diekmann/wasm-fizzbuzz</code></a>
<code>doom/</code> at commit <code>51a7030bea563d96027301a36619c17347b9270d</code>.</li>
<li>Local changes: see <code>patches/0001-chaos-and-majesty-doom-wasm.patch</code> for the
exact modifications applied during the Chaos &amp; Majesty build (audio bridge,
menu updates, wasm toolchain tweaks, and music playback shim).</li>
<li>Build steps and packaging guidance live in <code>docs/doom.md</code>.</li>
</ul>

<p>The DOOM engine is licensed under GPL-2.0-or-later. A copy of the license ships
with this repository as <code>COPYING</code>. Any redistribution of <code>doom.wasm</code> must
include:</p>
<ol>
<li>The GPL text (<code>COPYING</code>).</li>
<li>The complete corresponding source, which you can regenerate by applying the
patch above to the upstream repository and following the documented build
steps.</li>
</ol>
<p>If you further modify the engine, add your changes either to the existing patch
or as additional patches in this directory and document the update in
<code>docs/doom.md</code>.</p>
