<p>Before you ship, make sure to:</p>
<ul>
<li>✅ Update the site title, description, and meta keywords inside your YAML file.</li>
<li>✅ Replace the demo social preview image under <code>assets/static/img/</code>.</li>
<li>✅ Review the generated HTML in <code>site-output/</code> and ensure accessibility checks pass.</li>
<li>✅ Mirror your git repositories (optional) using the stagit instructions in the docs.</li>
</ul>
<p>Once everything looks good, rebuild the site and deploy the <code>site-output/</code> directory via your preferred platform.</p>
