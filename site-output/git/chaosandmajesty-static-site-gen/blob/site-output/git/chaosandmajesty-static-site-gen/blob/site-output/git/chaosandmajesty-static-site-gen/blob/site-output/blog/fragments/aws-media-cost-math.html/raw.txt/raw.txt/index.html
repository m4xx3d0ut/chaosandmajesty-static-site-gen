  26. <h2>Back of the Envelope AWS Media Cost Math</h2>
  27. <p>30 fps input
  28. 3 live hours</p>
  29. <p>MC Flows 2 - $0.16 each/hr = $0.96 +
  30. Input Bitrate = 10 Mbps
  31. <code>(10 Mbps / 8 = 1.25 MBps / 1024 = 0.00122 GBbps * 3600 = 4.4 GB per hour * 3) * 2</code> = 26.4 GB
  32. Total data transfer cost from MediaConnect to another AWS service in US East (N. Virginia) Region
  33. 26.4 * $0.01 = $0.26 +</p>
  34. <p>ML Channels 1 = 14.4 Mb/s
  35. Input HD $0.36 * 3 = $1.08 +
  36. Output &lt;=30fps $1.07 a/hr * 3 = $3.21 +</p>
  37. <p>MP Channel 1
  38. ingest $0.03 per GB
  39. 14.4 / 1024 * 60 * 60 = (50.625 / 8) * 0.03 = $0.18984375 * 3 = $0.56953125
  40. live origin $0.05 per GB
  41. 99% cache hit out 410.0625</p>
  42. <p>viewers 13824
  43. hours viewed 0.3</p>
  44. <p>13824 * 0.03 = 414.72 hrs
  45. (3 / 1024) * 60 * 60 / 8 = 1.318359375
  46. 414.72 * 1.318359375 = 546.75 * 0.01 = 5.4675 GB after cache * $0.05 = $0.273375</p>
  47. <p>2500 viewers
  48. 1.35 hours watched</p>
