  15. The demo theme is intentionally small so you can replace it without digging through hundreds of lines of styling. Here are a few quick wins:
  16. ​
  17. 1. Duplicate `examples/demo-site/assets/modern.css` and adjust the color variables at the top.
  18. 2. Swap the `styles` array in your YAML file so pages load your stylesheet.
  19. 3. Update any assets referenced in the Markdown files to match your colors or illustrations.
