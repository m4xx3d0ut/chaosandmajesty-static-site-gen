  10. ### TC Bottom Center
  11. ​
  12. To overlay time code on an MP4 video using ffmpeg from the Linux command line, you can use the drawtext filter. Here's an example command:
  13. ​
  14. ```bash
  15. ffmpeg -i input.mp4 -vf "drawtext=fontfile=/path/to/font.ttf:text='%{pts\:hms}':x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2" -c:a copy output.mp4
  16. ```
  17. ​
  18. Let's break down the command:
  19. ​
  20. - `-i input.mp4`: Specifies the input video file.
  21. - `-vf "drawtext=fontfile=/path/to/font.ttf:text='%{pts\:hms}':x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2"`: Applies the drawtext filter to overlay the time code on the video. Here's what each parameter does:
  22. - `fontfile`: Specifies the path to the font file you want to use. Replace `/path/to/font.ttf` with the actual path to your font file.
  23. - `text`: Sets the text to be displayed. `%{pts\:hms}` is a special variable that represents the current time in hours:minutes:seconds format.
  24. - `x` and `y`: Specify the position of the text on the video. `(w-tw)/2` centers the text horizontally, and `h-th-10` positions it 10 pixels from the bottom.
  25. - `fontsize`: Sets the font size of the text (e.g., 24).
  26. - `fontcolor`: Specifies the font color (e.g., white).
  27. - `bordercolor` and `borderw`: Sets the color and width of the text border (e.g., black and 2 pixels).
  28. - `-c:a copy`: Copies the audio stream from the input to the output without re-encoding.
  29. - `output.mp4`: Specifies the output video file.
  30. ​
  31. Make sure to replace `input.mp4` with the path to your actual input video file, and `output.mp4` with the desired name/path for the output file. Additionally, replace `/path/to/font.ttf` with the path to the font file you want to use for the time code overlay.**strong text**

  35. ### TC Centered in Frame
  36. ​
  37. To overlay time code with a font size of 48 on the center of the frame in an MP4 video using ffmpeg, you can use the following command:
  38. ​
  39. ```bash
  40. ffmpeg -i input.mp4 -vf "drawtext=fontfile=/path/to/font.ttf:fontsize=48:fontcolor=white:box=1:boxcolor=black@0.5:boxborderw=5:text='%{pts\:hms}':x=(w-tw)/2:y=(h/PHI)+th" -codec:a copy output.mp4
  41. ```
  42. ​
  43. Here's a breakdown of the command:
  44. ​
  45. - `-i input.mp4` specifies the input video file.
  46. - `-vf` is the video filter option used to apply the drawtext filter.
  47. - `drawtext` is the filter that allows drawing text on the video frames.
  48. - `fontfile=/path/to/font.ttf` sets the path to the font file you want to use. Replace `/path/to/font.ttf` with the actual path to the font file you want to use. Make sure to provide the correct path to the font file.
  49. - `fontsize=48` sets the font size to 48.
  50. - `box=1:boxcolor=black@0.5:boxborderw=5` adds a black semi-transparent box behind the text for better visibility. You can adjust the box color, transparency (0.5 in this example), and border width (5 in this example) as per your preference.
  51. - `text='%{pts\:hms}'` sets the text to be displayed as the time code in the format hours:minutes:seconds.
  52. - `x=(w-tw)/2:y=(h/PHI)+th` calculates the position of the text overlay to be centered on the frame. `x` determines the horizontal position, and `(w-tw)/2` ensures it is centered. `y` determines the vertical position, and `(h/PHI)+th` places it slightly above the center. You can adjust the vertical and horizontal positions based on your requirements.
  53. - `-codec:a copy` copies the audio stream from the input to the output without re-encoding, ensuring there is no loss in audio quality.
  54. - `output.mp4` is the output video file.
  55. ​
  56. Make sure to replace `input.mp4` with the path to your input video file and `output.mp4` with the desired output file name and extension.
