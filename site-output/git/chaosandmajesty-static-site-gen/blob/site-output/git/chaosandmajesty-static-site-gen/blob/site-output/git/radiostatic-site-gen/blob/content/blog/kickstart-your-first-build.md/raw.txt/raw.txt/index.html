  14. ​
  15. Ready to see RadioStatic in action? Start here:
  16. ​
  17. 1. Install dependencies with `npm install` (already done for the demo branch).
  18. 2. Run `./build-site.sh` to compile the demo configuration and generate HTML under `site-output/`.
  19. 3. Launch `make serve-local` to view the pages at [http://localhost:8080](http://localhost:8080).
  20. ​
  21. From there you can swap the YAML file, edit Markdown content, and rebuild. The entire flow runs offline so you can iterate quickly and keep your broadcast secure.
