        <h1>CM Static Site Deployment Guide</h1>
<p>This guide covers deploying the CM static site to Kubernetes using Flux GitOps.</p>
<h2>Overview</h2>
<p>The CM app is deployed as a static site generator with the following architecture:</p>
<ul>
<li><strong>Namespace</strong>: <code>web</code></li>
<li><strong>Image</strong>: <code>reg.microk8s.core.home.arpa:32000/cm:latest</code></li>
<li><strong>Ingress</strong>: <code>cm.core.home.arpa</code> with TLS</li>
<li><strong>Resources</strong>: Minimal footprint (50m CPU, 64Mi RAM)</li>
</ul>
<h2>Current Deployment Configuration</h2>
<p>Your deployment is currently configured with:</p>
<augment_code_snippet path="gitops/apps/cm/deployment.yaml" mode="EXCERPT">
````yaml
spec:
  replicas: 1
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 0
  resources:
    requests:
      cpu: 50m
      memory: 64Mi
    limits:
      cpu: 250m
      memory: 128Mi
````

<h2>Prerequisites</h2>
<ul>
<li>Flux installed and pointing to your <code>platform-config</code> repo</li>
<li>Ingress NGINX running with DNS for <code>cm.core.home.arpa</code></li>
<li>Nodes can pull from <code>reg.microk8s.core.home.arpa:32000</code></li>
<li>cert-manager with <code>local-ca</code> ClusterIssuer (for TLS)</li>
</ul>
<h2>Deployment Structure</h2>
<pre><code>gitops/apps/cm/
├── kustomization.yaml    # Kustomize configuration
├── namespace.yaml        # web namespace
├── deployment.yaml       # CM app deployment
├── service.yaml         # ClusterIP service
└── ingress.yaml         # NGINX ingress with TLS
</code></pre>
<h2>Verification Commands</h2>
<pre><code class="language-bash"># Check deployment status
kubectl -n web get deploy,svc,ingress,pods

# Check rollout status
kubectl -n web rollout status deploy/cm

# Test the endpoint
curl -H &quot;Host: cm.core.home.arpa&quot; https://cm.core.home.arpa/

# Check Flux reconciliation
flux get kustomizations -A
</code></pre>
<h2>Updating the Deployment</h2>
<h3>Method 1: Image Updates</h3>
<pre><code class="language-bash"># Build and push new image
docker build -t reg.microk8s.core.home.arpa:32000/cm:2025.01.15-1 .
docker push reg.microk8s.core.home.arpa:32000/cm:2025.01.15-1

# Update deployment manifest
yq -i &#39;.spec.template.spec.containers[0].image=&quot;reg.microk8s.core.home.arpa:32000/cm:2025.01.15-1&quot;&#39; gitops/apps/cm/deployment.yaml

# Commit and push
git commit -am &quot;cm: bump image to 2025.01.15-1&quot;
git push
</code></pre>
<h3>Method 2: Configuration Changes</h3>
<p>Edit the relevant YAML files in <code>gitops/apps/cm/</code>, commit, and push. Flux will automatically reconcile.</p>
<h2>Scaling for Different Traffic Levels</h2>
<h3>Production Readiness</h3>
<p>For production workloads, consider these improvements:</p>
<pre><code class="language-yaml">spec:
  replicas: 2  # High availability
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 0  # Zero-downtime updates
      maxSurge: 1
</code></pre>
<h3>Auto-scaling (Optional)</h3>
<p>Add horizontal pod autoscaler:</p>
<pre><code class="language-yaml">apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: cm-hpa
  namespace: web
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: cm
  minReplicas: 2
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70
</code></pre>
<h2>Security (Optional)</h2>
<p>Restrict network access to ingress controller only:</p>
<pre><code class="language-yaml">apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: cm-allow-ingress
  namespace: web
spec:
  podSelector:
    matchLabels:
      app: cm
  policyTypes: [&quot;Ingress&quot;]
  ingress:
    - from:
        - namespaceSelector:
            matchLabels:
              app.kubernetes.io/name: ingress-nginx
      ports:
        - port: 8080
          protocol: TCP
</code></pre>
<h2>Troubleshooting</h2>
<p><strong>Pod not starting:</strong></p>
<pre><code class="language-bash">kubectl -n web describe pod -l app=cm
kubectl -n web logs -l app=cm
</code></pre>
<p><strong>Ingress issues:</strong></p>
<pre><code class="language-bash">kubectl -n web describe ingress cm
kubectl get events -n web --sort-by=&#39;.lastTimestamp&#39;
</code></pre>
<p><strong>Flux not reconciling:</strong></p>
<pre><code class="language-bash">flux get sources git -A
flux reconcile kustomization apps -n flux-system
</code></pre>
<p>This deployment provides a solid foundation for the CM static site with room for scaling as traffic grows.</p>
