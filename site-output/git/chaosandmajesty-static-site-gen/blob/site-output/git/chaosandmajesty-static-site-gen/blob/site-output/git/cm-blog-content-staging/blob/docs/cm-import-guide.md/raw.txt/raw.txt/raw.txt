# Chaos & Majesty Sitegen Import Guide

Use this checklist whenever we promote fresh posts from `blog/` into the Chaos & Majesty site generator tree at `../../sshfs-mnt/chaosandmajesty-static-site-gen`. You can run `scripts/sync_cm_blog.py <posts-root> <cm-root>` to automate steps 2–4; the manual commands below describe what the script performs.

## 1. Prep the Source Material
- Regenerate publishable files so every markdown file contains the `## TLDR;` and `## Working Notes...` sections: `python3 scripts/apply_offsec_tldr.py && python3 scripts/format_blog.py --force`.
- Keep the sanitized hero assets under `blog/assets/<slug>/`. Only posts that declare `heroImage` need assets.
- Confirm the front matter uses one of the configured author IDs (`m4xx3d0ut`, `reneerules`, …) from `docs/blog-model.md`.

## 2. Copy Markdown into the Sitegen Repo
From the root of this repo:

```bash
rsync -av blog/*.md ../../sshfs-mnt/chaosandmajesty-static-site-gen/content/blog/
```

The generator reads straight from `content/blog/`, so no additional conversion is required.

## 3. Move Supporting Assets
For each folder under `blog/assets/` copy the files into the site generator’s blog asset tree (create the destination if it does not exist):

```bash
for dir in blog/assets/*; do
  slug="$(basename "$dir")"
  rsync -av "$dir"/ \
    ../../sshfs-mnt/chaosandmajesty-static-site-gen/static-sitegen/assets/static/img/blog/$slug/
done
```

If you also curate the design source (`cm-source/`) keep it in sync so `prepare-cm-files.sh` can be re-run later:

```bash
rsync -av blog/assets/ \
  ../../sshfs-mnt/chaosandmajesty-static-site-gen/cm-source/static/img/blog/
```

The build step copies everything from `static-sitegen/assets/` to `site-output/`, so a manual copy there is unnecessary.

## 4. Normalize `heroImage` Paths
Update each markdown file that references a hero image so the path matches the static asset location. Example replacement:

```yaml
heroImage: assets/rnd-methods-madness/freedom-glider-trash-panda.png
# becomes
heroImage: assets/static/img/blog/rnd-methods-madness/freedom-glider-trash-panda.png
```

Use `sed -i` for bulk edits or update manually before committing in the sitegen repo.

## 5. Build & Verify
Inside `../../sshfs-mnt/chaosandmajesty-static-site-gen`:

```bash
npm install   # first run only
npm run build || make preview
```

Open the generated `site-output/blog/index.html` (or run the preview server) and spot-check:
- TLDR and Working Notes render as expected.
- Hero images resolve correctly.
- Navigation lists the new posts by `publishedAt` order.

## 6. Commit & Ship
- Stage markdown plus any new assets in the sitegen repo.
- Reference the originating feature or issue in the commit message.
- Push and run the deployment workflow (or open a PR) per CM release practice.

Keep this guide alongside the repo so future imports stay consistent.
