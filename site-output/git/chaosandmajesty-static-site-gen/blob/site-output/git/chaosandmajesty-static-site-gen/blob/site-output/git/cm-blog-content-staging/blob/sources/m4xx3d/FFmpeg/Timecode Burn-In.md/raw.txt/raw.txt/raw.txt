### TC Bottom Center

To overlay time code on an MP4 video using ffmpeg from the Linux command line, you can use the drawtext filter. Here's an example command:

```bash
ffmpeg -i input.mp4 -vf "drawtext=fontfile=/path/to/font.ttf:text='%{pts\:hms}':x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2" -c:a copy output.mp4
```

Let's break down the command:

- `-i input.mp4`: Specifies the input video file.
- `-vf "drawtext=fontfile=/path/to/font.ttf:text='%{pts\:hms}':x=(w-tw)/2:y=h-th-10:fontsize=24:fontcolor=white:bordercolor=black:borderw=2"`: Applies the drawtext filter to overlay the time code on the video. Here's what each parameter does:
  - `fontfile`: Specifies the path to the font file you want to use. Replace `/path/to/font.ttf` with the actual path to your font file.
  - `text`: Sets the text to be displayed. `%{pts\:hms}` is a special variable that represents the current time in hours:minutes:seconds format.
  - `x` and `y`: Specify the position of the text on the video. `(w-tw)/2` centers the text horizontally, and `h-th-10` positions it 10 pixels from the bottom.
  - `fontsize`: Sets the font size of the text (e.g., 24).
  - `fontcolor`: Specifies the font color (e.g., white).
  - `bordercolor` and `borderw`: Sets the color and width of the text border (e.g., black and 2 pixels).
- `-c:a copy`: Copies the audio stream from the input to the output without re-encoding.
- `output.mp4`: Specifies the output video file.

Make sure to replace `input.mp4` with the path to your actual input video file, and `output.mp4` with the desired name/path for the output file. Additionally, replace `/path/to/font.ttf` with the path to the font file you want to use for the time code overlay.**strong text**

### TC Centered in Frame

To overlay time code with a font size of 48 on the center of the frame in an MP4 video using ffmpeg, you can use the following command:

```bash
ffmpeg -i input.mp4 -vf "drawtext=fontfile=/path/to/font.ttf:fontsize=48:fontcolor=white:box=1:boxcolor=black@0.5:boxborderw=5:text='%{pts\:hms}':x=(w-tw)/2:y=(h/PHI)+th" -codec:a copy output.mp4
```

Here's a breakdown of the command:

- `-i input.mp4` specifies the input video file.
- `-vf` is the video filter option used to apply the drawtext filter.
- `drawtext` is the filter that allows drawing text on the video frames.
- `fontfile=/path/to/font.ttf` sets the path to the font file you want to use. Replace `/path/to/font.ttf` with the actual path to the font file you want to use. Make sure to provide the correct path to the font file.
- `fontsize=48` sets the font size to 48.
- `box=1:boxcolor=black@0.5:boxborderw=5` adds a black semi-transparent box behind the text for better visibility. You can adjust the box color, transparency (0.5 in this example), and border width (5 in this example) as per your preference.
- `text='%{pts\:hms}'` sets the text to be displayed as the time code in the format hours:minutes:seconds.
- `x=(w-tw)/2:y=(h/PHI)+th` calculates the position of the text overlay to be centered on the frame. `x` determines the horizontal position, and `(w-tw)/2` ensures it is centered. `y` determines the vertical position, and `(h/PHI)+th` places it slightly above the center. You can adjust the vertical and horizontal positions based on your requirements.
- `-codec:a copy` copies the audio stream from the input to the output without re-encoding, ensuring there is no loss in audio quality.
- `output.mp4` is the output video file.

Make sure to replace `input.mp4` with the path to your input video file and `output.mp4` with the desired output file name and extension.
