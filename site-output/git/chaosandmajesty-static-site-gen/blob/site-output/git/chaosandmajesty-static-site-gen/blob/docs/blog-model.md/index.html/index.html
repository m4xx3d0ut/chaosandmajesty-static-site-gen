  14. <h1>Blog Content Model</h1>
  15. <p>The blog feature pulls structured metadata and markdown content into the static build so we can power HTMX-driven navigation without a live application server. All data is source-controlled and rendered at build time by <code>static-sitegen</code>.</p>
  16. <h2>Directory Layout</h2>
  17. <pre><code>content/
  18. blog/
  19. &lt;slug&gt;.md # Markdown body + YAML front matter per article
  20. ​
  21. static-sitegen/templates/blog/
  22. index.ejs # Blog landing page with post list + HTMX wiring
  23. post.ejs # Standalone full page variant for non-JS fallback
  24. fragment.ejs # Article-only snippet fetched via HTMX swaps
  25. </code></pre>
  26. <h2>Configuration (<code>smoke-test.yaml</code>)</h2>
  27. <pre><code class="language-yaml">blog:
  28. enabled: true
  29. postsDir: content/blog
  30. fragmentsDir: blog/fragments
  31. outputDir: blog
  32. indexTemplate: blog/index.ejs
  33. postTemplate: blog/post.ejs
  34. fragmentTemplate: blog/fragment.ejs
  35. authors:
  36. - id: m4xx3d0ut
  37. name: &quot;m4xx3d0ut&quot;
  38. title: &quot;Chaos Wrangler&quot;
  39. avatar: &quot;assets/static/img/authors/m4xx3d0ut.png&quot;
  40. bio: &quot;...
  41. - id: reneerules
  42. name: &quot;ReneéRules&quot;
  43. title: &quot;Majesty Maestro&quot;
  44. avatar: &quot;assets/static/img/authors/renee-rules.png&quot;
  45. bio: &quot;...
  46. index:
  47. heroTitle: &quot;Chaos &amp; Majesty Journal&quot;
  48. heroTagline: &quot;Dispatches from the underground&quot;
  49. ctaLabel: &quot;View latest&quot;
  50. </code></pre>
  51. <h3>Post Front Matter</h3>
  52. <p>Each blog markdown file must start with a YAML block providing metadata:</p>
  53. <pre><code class="language-yaml">---
  54. title: &quot;When the Console Glows&quot;
  55. slug: console-glows
  56. author: m4xx3d0ut
  57. summary: &quot;How we shaped the neon terminal aesthetic.&quot;
  58. publishedAt: 2024-05-05
  59. updatedAt: 2024-05-08
  60. readingMinutes: 6
  61. tags:
  62. - design
  63. - terminal
  64. heroImage: assets/static/img/blog/console-glows.webp
  65. ---
  66. </code></pre>
  67. <ul>
  68. <li><code>author</code> references one of the configured author IDs.</li>
  69. <li><code>publishedAt</code> drives sorting (newest first); <code>updatedAt</code> is optional.</li>
  70. <li><code>readingMinutes</code> renders as “X min read”.</li>
  71. <li>The remainder of the file is markdown content rendered with <code>marked</code>.</li>
  72. </ul>
  73. <h2>Generated Output</h2>
  74. <p>At build time we produce:</p>
  75. <ul>
  76. <li><code>site-output/blog.html</code> – HTMX-enabled landing page.</li>
  77. <li><code>site-output/blog/&lt;slug&gt;.html</code> – standalone article page, used for direct links and progressive enhancement.</li>
  78. <li><code>site-output/blog/fragments/&lt;slug&gt;.html</code> – article body partial fetched by HTMX swaps.</li>
  79. <li><code>site-output/blog/index.json</code> (optional future enhancement) could surface metadata for search.</li>
  80. </ul>
  81. <p>All pages inherit the CM console styling and include <code>hx-push-url</code> interactions so navigation and history back/forward feel native.</p>
