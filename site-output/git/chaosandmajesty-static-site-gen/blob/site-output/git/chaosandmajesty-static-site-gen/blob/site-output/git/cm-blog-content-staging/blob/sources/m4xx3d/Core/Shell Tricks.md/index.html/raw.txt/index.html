  40. <h2>Grep</h2>
  41. <p>In the <code>grep</code> command, you can use regular expressions to find patterns with wildcards. The wildcard symbol in regular expressions is <code>.</code> (dot), which matches any character. To match zero or more occurrences of the previous character or expression, you can use <code>*</code>. So, to find the pattern &quot;OS&quot; followed by any characters within curly braces, you can use the following <code>grep</code> command:</p>
  42. <pre><code class="language-bash">grep &#39;OS{.*}&#39; your_file.txt
  43. </code></pre>
  44. <p>In this command:</p>
  45. <ul>
  46. <li><code>grep</code> is the command for searching patterns in files.</li>
  47. <li><code>&#39;OS{.*}&#39;</code> is the regular expression pattern you&#39;re looking for. Here, <code>OS</code> matches the characters &quot;OS&quot;, <code>{</code> and <code>}</code> match themselves, and <code>.*</code> matches any sequence of characters (the dot <code>.</code> is a wildcard, and <code>*</code> means zero or more occurrences).</li>
  48. <li><code>your_file.txt</code> is the name of the file you want to search in. Replace it with the actual filename.</li>
  49. </ul>
  50. <p>Please note that curly braces <code>{}</code> are usually used for specifying repetition in regular expressions, so if you want to literally match curly braces, you might need to escape them with backslashes like this:</p>
  51. <pre><code class="language-bash">grep &#39;OS\{.*\}&#39; your_file.txt
  52. </code></pre>
  53. <p>Remember that <code>grep</code> uses basic regular expressions by default. If you&#39;re dealing with more complex patterns, you might need to use extended regular expressions by using the <code>-E</code> option:</p>
  54. <pre><code class="language-bash">grep -E &#39;OS\{.*\}&#39; your_file.txt
  55. </code></pre>
  56. <p>In Bash, you can split a string on the last occurrence of the forward slash (&quot;/&quot;) and retrieve the last element (file or directory name) by using parameter expansion. Here&#39;s how you can do it:</p>
  57. <pre><code class="language-bash">path=&quot;/path/to/your/directory/file.txt&quot;
  58. # Use parameter expansion to split on the last &quot;/&quot;
  59. last_element=&quot;${path##*/}&quot;
  60. echo &quot;Last element: $last_element&quot;
  61. </code></pre>
  62. <p>If you want to iterate through all files in the current working directory (<code>pwd</code>), you can do so with the following one-liner:</p>
  63. <pre><code class="language-bash">for file in &quot;$(pwd)&quot;/*; do [ -f &quot;$file&quot; ] &amp;&amp; echo &quot;Processing file: $file&quot;; done
  64. </code></pre>
  65. <p>To iterate through all files in a directory using a Bash script, you can use a <code>for</code> loop and the <code>*</code> wildcard to match all files in the directory. Here&#39;s a basic example of how to do this:</p>
  66. <pre><code class="language-bash">#!/bin/bash
  67. ​
  68. # Specify the directory you want to iterate through
  69. directory=&quot;/path/to/your/directory&quot;
  70. ​
  71. # Use a for loop to iterate through the files
  72. for file in &quot;$directory&quot;/*; do
  73. if [ -f &quot;$file&quot; ]; then
  74. echo &quot;Processing file: $file&quot;
  75. # You can perform operations on &quot;$file&quot; here
  76. fi
  77. done
  78. </code></pre>
  79. <h2>Find and Replace String Recursively</h2>
  80. <p>Command breakdown</p>
  81. <p>grep -r: --recursive, recursively read all files under each directory.
  82. grep -l: --print-with-matches, prints the name of each file that has a match, instead of printing matching lines.
  83. grep -i: --ignore-case.</p>
  84. <p>xargs: transform the STDIN to arguments.
  85. xargs -i@ <del>command contains @</del>: a placeholder for the argument to be used in a specific position in the <del>command</del>, the @ sign is a placeholder which could replaced by any string.</p>
  86. <p>sed -i: edit files in place, without backups.
  87. sed s/regexp/replacement/: substitute string matching regexp with replacement.
  88. sed s/regexp/replacement/g: global, make the substitution for each match instead of only the first match.</p>
  89. <pre><code>grep -rli &#39;old-word&#39; * | xargs -i@ sed -i &#39;s/old-word/new-word/g&#39; @
  90. </code></pre>
