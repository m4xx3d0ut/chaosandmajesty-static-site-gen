  31. <h2>TLDR;</h2>
  32. <ul>
  33. <li>Use <code>tee</code> to capture stdout to both the terminal and a log, and lean on <code>jq</code> for rapid pretty-printing or minifying JSON.</li>
  34. <li>Remember the regex basics for <code>grep</code>, including escaping braces and switching to <code>-E</code> for extended features.</li>
  35. <li>Combine <code>grep -rl</code> with <code>xargs</code> and <code>sed -i</code> for project-wide search-and-replace, and use parameter expansion (<code>${path##*/}</code>) to grab filenames within loops.</li>
  36. </ul>
  37. <h2>Working Notes... In Graphic Detail...</h2>
  38. <h3>STDOUT Redirection</h3>
  39. <p>Write STDOUT to console and file:</p>
  40. <pre><code class="language-bash">command | tee command.log
  41. </code></pre>
  42. <h3>JSON Helpers</h3>
  43. <p>Pretty-print JSON:</p>
  44. <pre><code class="language-bash">jq . sample.json &gt; pretty.json
  45. </code></pre>
  46. <p>Minify JSON:</p>
  47. <pre><code class="language-bash">jq -c &lt; pretty.json
  48. </code></pre>
  49. <h3>JSON Diffing</h3>
  50. <p>Diff an application bundle after pretty-printing:</p>
  51. <pre><code class="language-bash">cat min/skybox-default-streams.json.live.min | jq . &gt; test.json
  52. ​
  53. diff -y -d test.json pp-skybox-default-streams.json
  54. </code></pre>
  55. <h3><code>grep</code> Patterns and Wildcards</h3>
  56. <p>Match <code>OS{...}</code> blocks with basic regex:</p>
  57. <pre><code class="language-bash">grep &#39;OS\{.*\}&#39; your_file.txt
  58. </code></pre>
  59. <p>Switch to extended regex if you want the shorthand without escaping braces:</p>
  60. <pre><code class="language-bash">grep -E &#39;OS{.*}&#39; your_file.txt
  61. </code></pre>
  62. <h3>Path and Loop Utilities</h3>
  63. <p>Grab the last path element with parameter expansion:</p>
  64. <pre><code class="language-bash">path=&quot;/path/to/your/directory/file.txt&quot;
  65. last_element=&quot;${path##*/}&quot;
  66. echo &quot;Last element: $last_element&quot;
  67. </code></pre>
  68. <p>Iterate through files in the current directory:</p>
  69. <pre><code class="language-bash">for file in &quot;$(pwd)&quot;/*; do
  70. [ -f &quot;$file&quot; ] &amp;&amp; echo &quot;Processing file: $file&quot;
  71. done
  72. </code></pre>
  73. <p>Template script to walk a directory:</p>
  74. <pre><code class="language-bash">#!/bin/bash
  75. ​
  76. # Directory to iterate
  77. directory=&quot;/path/to/your/directory&quot;
  78. ​
  79. for file in &quot;$directory&quot;/*; do
  80. if [ -f &quot;$file&quot; ]; then
  81. echo &quot;Processing file: $file&quot;
  82. # Add work here
  83. fi
  84. done
  85. </code></pre>
  86. <h3>Recursive Find &amp; Replace</h3>
  87. <p>Search recursively, emit matching filenames, and replace text in place:</p>
  88. <pre><code class="language-bash">grep -rli &#39;old-word&#39; . | xargs -I@ sed -i &#39;s/old-word/new-word/g&#39; @
  89. </code></pre>
  90. <p><code>grep</code> flags:</p>
  91. <ul>
  92. <li><code>-r</code> — recurse directories</li>
  93. <li><code>-l</code> — print matching filenames</li>
  94. <li><code>-i</code> — ignore case</li>
  95. </ul>
  96. <p><code>xargs -I@ ... @</code> injects each filename into the <code>sed</code> command. The <code>sed -i</code> flag edits files in place, and the trailing <code>g</code> applies the substitution globally per line.</p>
