## Shield Tablet K1

SD card bind mount for Kali RootFS
```
su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
```

[Magisk Boot Script](https://github.com/topjohnwu/Magisk/blob/master/docs/guides.md#boot-scripts) to create bind mount and output to logcat.
```
shieldtablet:/ $ su
shieldtablet:/ # cat /data/adb/service.d/nhbind.sh
#!/system/bin/sh
{
# Bind mount ext sdcard nhsys to internal nhsystem
su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
} | tee /dev/tty | while read line; do
 log -p v -t "$0" "$line"
done
```


Termux boot mount `.termux/boot/nhbind`
```
#!/data/data/com.termux/files/usr/bin/sh
# Bind mount ext sdcard nhsys to internal nhsystem
su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
```


Install apks from dir
```
for i in $(ls); echo $i; adb install -r $i
```

List installed 3rd party packages
```
adb shell pm list packages -f -3
```

OP One LineageOS defconfig
```
kernel/oppo/msm8974/arch/arm/configs/lineageos_bacon_defconfig
```

Metasploit Postgres connection to Termux Postgresql, avoids issues with SYSVIPC SHMMEM in Kali chroot.
```
# Termux shell
pkg update && pkg install openssl-tool postgresql
mkdir {/path/to/db/dir}
pg_ctl initdb -D {/path/to/db/dir}
pg_ctl -D {/path/to/db/dir} start
pg_ctl -D {/path/to/db/dir} stop
createuser --superuser --pwprompt msf
pw: LmnKsFF962a1

# psql shell
psql postgres
CREATE DATABASE msf;
\l
\q

# kali shell
msfconsole
db_connect msf:LmnKsFF962a1@127.0.0.1/msf
db_status
```
