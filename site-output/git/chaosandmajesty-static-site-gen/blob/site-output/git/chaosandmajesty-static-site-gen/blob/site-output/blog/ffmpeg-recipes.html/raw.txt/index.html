  94. <div class="blog-article-content">
  95. <ul>
  96. <li>Use <code>-ss</code>/<code>-t</code> with <code>-c copy</code> to clip segments without re-encoding, and rely on <code>libx264</code>/<code>libx265</code> (or <code>h264_nvenc</code>) when you need transcodes.</li>
  97. <li>Loop still images or test patterns with <code>-loop 1</code> and <code>lavfi</code> sources, then concat segments via a manifest to reach longer runtimes.</li>
  98. <li>The <code>drawtext</code> filter handles timecode overlays; remember to point to a valid font and position text with expressions like <code>(w-tw)/2</code>.</li>
  99. </ul>
  100. <h2>Working Notes... In Graphic Detail...</h2>
  101. <h3>Transcode 4K MOV to 1080p H.264 AAC</h3>
  102. <pre><code class="language-bash">ffmpeg -i input.mov -vf &quot;scale=1920:1080&quot; -c:v libx264 -crf 23 -c:a aac -b:a 192k output.mp4
  103. </code></pre>
  104. <p>Hardware-accelerated NVENC variant:</p>
  105. <pre><code class="language-bash">ffmpeg -i input.mov -vf &quot;scale=1920:1080&quot; -c:v h264_nvenc -rc:v vbr_hq -b:v 8M -pix_fmt yuv420p -c:a aac -b:a 192k output.mp4
  106. </code></pre>
  107. <p>Reduce file size with HEVC:</p>
  108. <pre><code class="language-bash">ffmpeg -i input.mp4 -c:v libx265 -crf 28 -c:a copy output.mp4
  109. </code></pre>
  110. <p>Batch transcode current directory to an <code>out/</code> folder:</p>
  111. <pre><code class="language-bash">mkdir -p out
  112. for file in &quot;$(pwd)&quot;/*; do
  113. [ -f &quot;$file&quot; ] || continue
  114. ffmpeg -y -i &quot;$file&quot; -c:v libx264 -crf 28 -c:a copy &quot;$(pwd)&quot;/out/&quot;${file##*/}&quot;
  115. done
  116. </code></pre>
  117. <h3>Clip a Segment</h3>
  118. <pre><code class="language-bash">ffmpeg -ss 00:00:00 -t 00:00:20 -i input.mp4 -c copy output.mp4
  119. </code></pre>
  120. <h3>1-Minute SCTE Test Pattern (MJPEG)</h3>
  121. <pre><code class="language-bash">ffmpeg -f lavfi -i testsrc=size=1920x1080:rate=30 -t 60 -c:v mjpeg -an output_test_pattern.mjpeg
  122. </code></pre>
  123. <h3>1 kHz Audio Tone (60 seconds)</h3>
  124. <pre><code class="language-bash">ffmpeg -f lavfi -i sine=frequency=1000:duration=60 -c:a pcm_s16le audio.wav
  125. </code></pre>
  126. <h3>Bouncing Ball Test Pattern (excerpt)</h3>
  127. <p>Generate a five-minute MJPEG test clip with moving graphics:</p>
  128. <pre><code class="language-bash">ffmpeg -f lavfi -i &quot;testsrc=size=1920x1080:rate=30&quot; \
  129. -f lavfi -i &quot;life=s=1920x1080:mold=10:r=30:ratio=0.1:death_color=black:life_color=white&quot; \
  130. -filter_complex &quot;overlay&quot; -t 300 -c:v mjpeg -an bouncing-ball.mjpeg
  131. </code></pre>
  132. <h3>Loop a Single Image</h3>
  133. <p>Resize as needed (ImageMagick):</p>
  134. <pre><code class="language-bash">convert input.png -resize 1920x1080 frame.png
  135. </code></pre>
  136. <p>Build a 10-minute, 30 FPS loop:</p>
  137. <pre><code class="language-bash">ffmpeg -loop 1 -i frame.png -t 600 -r 30 -pix_fmt yuv420p loop-10min.mp4
  138. </code></pre>
  139. <p>Concatenate six loops into an hour-long clip:</p>
  140. <pre><code class="language-bash">for i in {1..6}; do echo &quot;file &#39;loop-10min.mp4&#39;&quot; &gt;&gt; concat.lst; done
  141. ffmpeg -f concat -safe 0 -i concat.lst -c copy loop-60min.mp4
  142. </code></pre>
  143. <h3>Burn-In Timecode</h3>
  144. <p>Top-left overlay (adjust font path):</p>
  145. <pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:fontsize=32:fontcolor=white:\
  146. box=1:boxcolor=black@0.5:boxborderw=5:text=&#39;%{pts\:hms}&#39;:x=20:y=20&quot; -c:a copy output.mp4
  147. </code></pre>
  148. <p>Centered overlay with golden-ratio offset:</p>
  149. <pre><code class="language-bash">ffmpeg -i input.mp4 -vf &quot;drawtext=fontfile=/path/to/font.ttf:fontsize=48:fontcolor=white:\
  150. box=1:boxcolor=black@0.5:boxborderw=5:text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=(h/PHI)+th&quot; -c:a copy output.mp4
  151. </code></pre>
  152. <p>Sample grabbing from an HLS stream and exporting a 20-second clip with timecode:</p>
  153. <pre><code class="language-bash">ffmpeg -ss 00:04:30 -t 20 -i https://example.com/endpoint/index.m3u8 \
  154. -vf &quot;drawtext=fontsize=48:fontcolor=white:box=1:boxcolor=black@0.5:boxborderw=5:\
  155. text=&#39;%{pts\:hms}&#39;:x=(w-tw)/2:y=(h/PHI)+th&quot; -c:a copy clip-with-tc.mp4
  156. </code></pre>
  157. <h3>Quick Reference Commands</h3>
  158. <ul>
  159. <li>Create an MJPEG video test card and matching sine-wave audio tone for end-to-end testing.</li>
  160. <li>Loop a still image via <code>-loop 1</code> and use the concat demuxer to extend the runtime.</li>
  161. <li>Clip segments with <code>-ss</code>/<code>-t</code>, preserving audio with <code>-c:a copy</code>.</li>
  162. <li>Switch between software (<code>libx264</code>, <code>libx265</code>) and hardware (<code>h264_nvenc</code>) encoders depending on the workstation.</li>
  163. </ul>
