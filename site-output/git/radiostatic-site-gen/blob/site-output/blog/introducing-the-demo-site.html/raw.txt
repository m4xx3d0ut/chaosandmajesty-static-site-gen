  <div class="blog-article-content">
    <p>The demo project is built to be minimal yet complete so you can remix it quickly. Here is how each piece participates in the build:</p>
<h3>Configuration</h3>
<p>The <code>smoke-test.yaml</code> file describes the overall site metadata, sections, and blog settings. Swap in your own YAML file by running <code>./build-site.sh path/to/config.yaml</code> and RadioStatic will generate the output accordingly.</p>
<h3>Content</h3>
<p>Blog posts live in <code>content/blog/</code> and may include <a href="https://www.markdownguide.org/basic-syntax/">Markdown</a> or inline HTML. Each file uses YAML front matter to describe metadata and the <code>author</code> field maps to an entry defined in the main configuration file.</p>
<h3>Assets</h3>
<p>Place CSS, JavaScript, and image files under the directory referenced by the <code>assets</code> key in the YAML file. In the demo we use <code>examples/demo-site/assets/</code>, but you can point to any folder.</p>
<h3>Templates</h3>
<p>EJS templates under <code>static-sitegen/templates/</code> render the pages. Most projects can stick with the defaults; advanced users can copy and customize them.</p>
<blockquote>
<p>Tip: Run <code>make serve-local</code> to host the <code>site-output/</code> directory at <code>http://localhost:8080</code> for quick previews.</p>
</blockquote>
<p>Happy building!</p>
