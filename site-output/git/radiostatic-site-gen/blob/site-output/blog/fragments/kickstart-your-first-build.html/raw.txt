    <p>Ready to see RadioStatic in action? Start here:</p>
<ol>
<li>Install dependencies with <code>npm install</code> (already done for the demo branch).</li>
<li>Run <code>./build-site.sh</code> to compile the demo configuration and generate HTML under <code>site-output/</code>.</li>
<li>Launch <code>make serve-local</code> to view the pages at <a href="http://localhost:8080">http://localhost:8080</a>.</li>
</ol>
<p>From there you can swap the YAML file, edit Markdown content, and rebuild. The entire flow runs offline so you can iterate quickly and keep your broadcast secure.</p>
