  29. <div class="blog-article-content">
  30. <p>Ready to see RadioStatic in action? Start here:</p>
  31. <ol>
  32. <li>Install dependencies with <code>npm install</code> (already done for the demo branch).</li>
  33. <li>Run <code>./build-site.sh</code> to compile the demo configuration and generate HTML under <code>site-output/</code>.</li>
  34. <li>Launch <code>make serve-local</code> to view the pages at <a href="http://localhost:8080">http://localhost:8080</a>.</li>
  35. </ol>
  36. <p>From there you can swap the YAML file, edit Markdown content, and rebuild. The entire flow runs offline so you can iterate quickly and keep your broadcast secure.</p>
