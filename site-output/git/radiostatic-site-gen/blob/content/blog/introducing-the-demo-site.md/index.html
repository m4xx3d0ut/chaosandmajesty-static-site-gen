The demo project is built to be minimal yet complete so you can remix it quickly. Here is how each piece participates in the build:

Configuration

The smoke-test.yaml file describes the overall site metadata, sections, and blog settings. Swap in your own YAML file by running ./build-site.sh path/to/config.yaml and RadioStatic will generate the output accordingly.

Content

Blog posts live in content/blog/ and may include Markdown or inline HTML. Each file uses YAML front matter to describe metadata and the author field maps to an entry defined in the main configuration file.

Assets

Place CSS, JavaScript, and image files under the directory referenced by the assets key in the YAML file. In the demo we use examples/demo-site/assets/, but you can point to any folder.

Templates

EJS templates under static-sitegen/templates/ render the pages. Most projects can stick with the defaults; advanced users can copy and customize them.

Tip: Run make serve-local to host the site-output/ directory at http://localhost:8080 for quick previews.

Happy building!
