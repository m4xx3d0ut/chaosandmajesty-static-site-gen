Ready to see RadioStatic in action? Start here:

  1. Install dependencies with npm install (already done for the demo branch).
  2. Run ./build-site.sh to compile the demo configuration and generate HTML under site-output/.
  3. Launch make serve-local to view the pages at http://localhost:8080.

From there you can swap the YAML file, edit Markdown content, and rebuild. The entire flow runs offline so you can iterate quickly and keep your broadcast secure.
