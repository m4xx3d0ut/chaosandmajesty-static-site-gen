  <h1>Core Local - Install Our Internal Root CA</h1>
  <p>Download the certificate for your device and verify its fingerprint before trusting it.</p>

  <div class="card grid">
    <div><strong>Downloads</strong></div>
    <div>
      <a class="btn" href="/downloads/org-root-ca.crt">PEM (.crt)</a>
      <a class="btn" href="/downloads/org-root-ca.der">DER (.der)</a>
    </div>
    <div><strong>Expected SHA-256 fingerprint</strong></div>
    <div><code>SHA256: F2:78:8D:51:84:7E:88:AD:0B:A1:D1:B3:EC:55:56:1A:A6:37:FB:D5:7C:5C:F3:AC:36:32:C7:D1:8C:24:31:FE</code></div>
  </div>

  <div class="card">
    <h3>Verify fingerprint</h3>
    <p><b>Linux/macOS</b></p>
    <pre>openssl x509 -noout -fingerprint -sha256 -in ~/Downloads/org-root-ca.crt</pre>
    <p><b>Windows (PowerShell)</b></p>
    <pre>Get-FileHash -Path "$env:USERPROFILE\Downloads\org-root-ca.cer" -Algorithm SHA256</pre>
  </div>

  <div class="card">
    <h3>Install on your device</h3>

    <p><b>Ubuntu/Debian</b></p>
<pre>sudo cp ~/Downloads/org-root-ca.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates</pre>

    <p><b>RHEL/Rocky/Alma</b></p>
<pre>sudo cp ~/Downloads/org-root-ca.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust</pre>

    <p><b>macOS</b></p>
<pre>sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/Downloads/org-root-ca.crt</pre>

    <p><b>Windows</b> (local machine)</p>
<pre>certutil -f -addstore "Root" "%USERPROFILE%\Downloads\org-root-ca.cer"</pre>

    <p><b>iOS/iPadOS</b></p>
    <p>Download the <b>DER</b> file, go to <i>Settings → General → VPN & Device Management</i> (or <i>Profiles</i>), install the profile, then enable full trust under <i>Settings → General → About → Certificate Trust Settings</i>.</p>

    <p><b>Android</b></p>
    <p>Download the <b>DER</b> file → <i>Settings → Security → Encryption & credentials → Install a certificate → CA certificate</i>. (Best is via MDM as a <i>system</i> CA.)</p>

    <p><b>Firefox (Linux)</b></p>
<pre>about:config → set <b>security.enterprise_roots.enabled</b> to <b>true</b></pre>
  </div>

  <div class="card">
    <h3>Notes</h3>
    <ul>
      <li>Restart browsers/apps after install to pick up the new trust store.</li>
      <li>Wildcard certs cover one label only (e.g. <code>*.core.home.arpa</code>).</li>
      <li>Some apps use their own CA store—point them at the PEM if needed.</li>
    </ul>
