To create a minute-long SCTE test pattern video in MJPEG format with no audio using ffmpeg, you can use the following command:

ffmpeg -f lavfi -i testsrc=size=1920x1080:rate=30 -t 60 -c:v mjpeg -an output_test_pattern.mjpeg

Explanation of the command:

  • ffmpeg: The command to invoke ffmpeg.
  • -f lavfi -i testsrc=size=1920x1080:rate=30: This tells ffmpeg to use the testsrc filter to generate a test pattern video. The size of the video is set to 1920x1080, and the frame rate is set to 30 frames per second.
  • -t 60: Specifies the duration of the video, in this case, 60 seconds (1 minute).
  • -c:v mjpeg: This sets the video codec to MJPEG for the output file.
  • -an: This option disables audio in the output file.
  • output_test_pattern.mjpeg: The name of the output file. You can change this to your desired filename and location.

When you run this command, ffmpeg will generate a one-minute long SCTE test pattern video in MJPEG format with a resolution of 1920x1080 and a frame rate of 30 fps, with no audio. The output file will be named "output_test_pattern.mjpeg" in the current working directory.

To generate a one-minute long audio test tone and save it as "audio.wav" using ffmpeg, you can use the following command:

ffmpeg -f lavfi -i sine=frequency=1000:duration=60 -c:a pcm_s16le audio.wav

Explanation of the command:

  • ffmpeg: The command to invoke ffmpeg.
  • -f lavfi -i sine=frequency=1000:duration=60: This tells ffmpeg to use the sine audio filter to generate a sinusoidal audio tone with a frequency of 1000 Hz and a duration of 60 seconds (1 minute).
  • -c:a pcm_s16le: This sets the audio codec to PCM signed 16-bit little-endian, which is a lossless format suitable for WAV files.
  • audio.wav: The name of the output audio file. The generated audio test tone will be saved as "audio.wav" in the current working directory.

When you run this command, ffmpeg will create a one-minute long audio test tone with a frequency of 1000 Hz and save it as "audio.wav" in WAV format. Adjust the frequency value (1000 Hz in this case) to change the pitch of the test tone if needed.

Creating a 5-minute long video test pattern with a bouncing ball in MJPEG format requires combining two inputs: a test pattern video and a video with the animated bouncing ball. We can use the testsrc filter for the test pattern and the life filter for the animated bouncing ball. Here's the ffmpeg command to achieve this:

ffmpeg -f lavfi -i testsrc=size=1280x720:rate=30 -f lavfi -i life=s=1280x720:rate=30 -t 300 -filter_complex "[0:v]drawtext=text='Test Pattern':fontcolor=white:fontsize=50:x=(w-text_w)/2:y=(h-text_h)/2[tp];[tp][1:v]overlay=x='if(gte(t,1),(W-w)/2+((W-w)/2-ow)/299*(t-1)*2,(W-w)/2)':y='if(gte(t,1),(H-h)/2+((H-h)/2-oh)/299*(t-1)*2,(H-h)/2)'" -c:v mjpeg -an output_test_pattern_bouncing_ball.mjpeg

Explanation of the command:

  • ffmpeg: The command to invoke ffmpeg.
  • -f lavfi -i testsrc=size=1280x720:rate=30: This input generates the test pattern video using the testsrc filter. The size of the video is set to 1280x720, and the frame rate is 30 fps.
  • -f lavfi -i life=s=1280x720:rate=30: This input generates the video with the animated bouncing ball using the life filter. The size of the video is also set to 1280x720, and the frame rate is 30 fps.
  • -t 300: Specifies the duration of the output video, in this case, 300 seconds (5 minutes).
  • -filter_complex: This option allows us to apply complex filtergraphs, where we combine the test pattern and the animated bouncing ball.
  • "drawtext=text='Test Pattern':fontcolor=white:fontsize=50:x=(w-text_w)/2:y=(h-text_h)/2[tp]": This draws the text "Test Pattern" on the test pattern video, positioning it in the center.
  • [tp][1:v]overlay=x='if(gte(t,1), (W-w)/2 + ((W-w)/2-ow)/299*(t-1)*2, (W-w)/2)':y='if(gte(t,1), (H-h)/2 + ((H-h)/2-oh)/299*(t-1)*2, (H-h)/2)': This overlays the test pattern video (tp) with the animated bouncing ball (1:v) using the overlay filter. The ball starts bouncing after 1 second (time t >= 1), and its position is calculated using linear interpolation to give a bouncing effect.
  • -c:v mjpeg: This sets the video codec to MJPEG for the output file.
  • -an: This option disables audio in the output file.
  • output_test_pattern_bouncing_ball.mjpeg: The name of the output file. The generated video test pattern with a bouncing ball will be saved as "output_test_pattern_bouncing_ball.mjpeg" in the current working directory.

When you run this command, ffmpeg will create a 5-minute long video with a test pattern and a bouncing ball animation in MJPEG format. The output file will be named "output_test_pattern_bouncing_ball.mjpeg."

  • The between function is used to set the start and end points for each stage of the ball's motion.
