# Software Defined Radio References

- Passive radar tutorial using dual RTL-SDR dongles: <https://www.rtl-sdr.com/a-fm-radio-passive-radar-system-from-two-rtl-sdr-dongles/>
- GitHub implementation (`passiveRadar`): <https://github.com/Max-Manning/passiveRadar>
- Recommended hardware: *RTL-SDR Blog V3 R860 RTL2832U 1PPM TCXO SMA Software Defined Radio* — <https://a.co/d/9PiepSK>. The V3 includes an aluminium enclosure, passive cooling, and supports direct sampling for HF (with reduced performance).
- Note: the V3 can be modified to share a reference clock for phase-coherent setups.

## Broadcast Frequency Cheat Sheet

TV channel assignments span 54–806 MHz, divided into 68 channels, each 6 MHz wide. To derive the picture carrier for a channel, add **1.25 MHz** to the lower bound of its frequency range.
