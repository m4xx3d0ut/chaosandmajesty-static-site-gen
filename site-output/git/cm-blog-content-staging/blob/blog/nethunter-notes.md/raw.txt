## TLDR;

- Use `su --mount-master` to bind the external SD card into `/data/local/nhsystem` so NetHunter has room for its root filesystem.
- Automate the bind mount with Magisk or Termux boot scripts so the chroot is ready after every reboot.
- Point Metasploit at a Termux-hosted PostgreSQL instance to dodge shared-memory issues inside the NetHunter chroot.

## Working Notes... In Graphic Detail...

### Shield Tablet K1 Mounts

Bind-mount the SD card into the NetHunter rootfs:
```
bash
su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
```

Magisk boot script (`/data/adb/service.d/nhbind.sh`) to recreate the bind mount and log to logcat:
```
bash
#!/system/bin/sh
{
  # Bind mount ext sdcard nhsys to internal nhsystem
  su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
} | tee /dev/tty | while read line; do
  log -p v -t "$0" "$line"
done
```

Termux boot script (`~/.termux/boot/nhbind`):
```
bash
#!/data/data/com.termux/files/usr/bin/sh
su --mount-master -c "mount --bind /storage/emulated/0/nhsys/ /data/local/nhsystem/"
```

### APK Automation

Install every APK in the current directory:
```
bash
for i in *; do
  echo "$i"
  adb install -r "$i"
done
```

List third-party packages:
```
bash
adb shell pm list packages -f -3
```

### Metasploit + Termux PostgreSQL

Run PostgreSQL in Termux to back Metasploit:
```
bash
pkg update && pkg install openssl-tool postgresql
mkdir /path/to/db
pg_ctl initdb -D /path/to/db
pg_ctl -D /path/to/db start
pg_ctl -D /path/to/db stop
createuser --superuser --pwprompt msf
# Suggested password: generate your own secret instead of reusing samples.
```

Inside `psql`:
```
bash
psql postgres
CREATE DATABASE msf;
\l
\q
```

Connect from Kali:
```
bash
msfconsole
db_connect msf:<password>@127.0.0.1/msf
db_status
```
