AI System – Single Source of Truth (Gateway + vLLM on RTX 8000/Turing)

Purpose: Single reference for design, manifests, and ops to meet requirements:

  • Serve multiple open‑weight models on a Quadro RTX 8000 (SM 7.5) with vLLM.
  • Provide a Gateway that supports Direct and Routed modes and abstracts OpenAI/Gemini.
  • Hot‑load local models on demand; purge model cache safely.
  • GitOps via Flux; production‑safe NetworkPolicy, probes, and Turing‑specific tuning.

0) Architecture

Per‑model vLLM Deployments (Option A)

  • One Deployment per local model (e.g., vllm-glm-edge-1p5b, vllm-glm-edge-4b, vllm-glm-45-air).
  • Each exposes OpenAI‑compatible API on port 8000 and ships with a cachectl sidecar on 8081.
  • Hot‑loading == scaling a Deployment 0 ↔ 1. Purging == unload then tell cachectl to delete the HF cache dir.

Gateway

  • Single FastAPI service that:

    • Direct mode: model:"local:<repo>" | "openai:<model>" | "gemini:<model>".
    • Routed mode: model:"routed", with task (e.g., chat, classify) resolved via the routing ConfigMap.
    • /v1/models (inventory), /admin/hotload, /admin/unload, /admin/purge-cache, /admin/prompts, **/admin/routing`.
    • Optional ADMIN_TOKEN header guards admin endpoints.

  • Knows each local model’s Service and Deployment name for routing/scale.

GitOps

  • All manifests under ai-system-config/k8s/base/* + overlay k8s/overlays/prod.
  • Flux Kustomization references overlay (from platform repo).

3) Gateway Implementation (features)

  • Inventory: GET /v1/models → lists local models + provider availability (OpenAI/Gemini) + readiness/replicas.

  • Direct: POST /v1/chat/completions with model:"local:<repo>" | "openai:<model>" | "gemini:<model>".

  • Routed: same endpoint with model:"routed" and task:"chat"|"classify"|…; picks weighted ready targets from routing CM.

  • Admin (optional X-Admin-Token):

    • POST /admin/hotload {"model":"local:<repo>"} → scales that model to 1
    • POST /admin/unload {…} → scales to 0
    • POST /admin/purge-cache {…} → requires replicas=0, then hits sidecar /purge?repo_id=
    • GET /admin/prompts / POST /admin/prompts → update in‑memory prompt templates
    • GET /admin/routing → current loaded routing + resourceVersion

  • Hot‑reload routing: watches routing ConfigMap (poll), picks up weight/target changes automatically.

The gateway code already includes: OpenAI SDK, Gemini SDK, Kubernetes client (in‑cluster); task wiring; prompt templating hooks.

5) Extended Troubleshooting – Turing (SM 7.5)

Symptom → Fix matrix

Symptom (log/error) Why on SM 7.5 Fix
TopPSamplingFromProbs … too many resources requested for launch FlashInfer sampling issue Set VLLM_USE_FLASHINFER=0 (and/or VLLM_USE_FLASHINFER_SAMPLER=0)
Cannot use FA version 2 … compute capability >= 8 FA2 needs Ampere+ Expected on Turing; it falls back.
Your device … doesn't support torch.bfloat16 No BF16 Use --dtype float16.
VLLM_PORT 'tcp://…' appears to be a URI K8s service env collision enableServiceLinks:false and/or set container env VLLM_PORT="39000".
Name resolution / HF download errors NetPol/DNS block Allow UDP/TCP 53 egress; allow TCP 80/443 for vllm/gateway.
Restarts during warmup/compile Probes too aggressive Add startupProbe on /health with ~5 min window.
Pod Pending GPU scheduling Node label accelerator=nvidia, NVIDIA device plugin, nvidia.com/gpu: 1.

6) Security & Ops notes

  • Secrets: never commit tokens; rotate any previously exposed HF tokens and re‑create hf-token Secret.
  • Admin endpoints: protect with ADMIN_TOKEN + NetworkPolicy (cluster‑internal only) until you front with auth.
  • Image pinning: pin vllm/vllm-openai to a tested tag once stable (avoid :latest).
  • Canary: re‑enable Flagger once base is green. Update loadtest path to /v1/models or a cheap health.
  • Observability: set OTEL envs via otel-resource ConfigMap; forward to your collector.

7) Checklists

Day‑1 bring‑up

  • Label GPU node accelerator=nvidia and verify device plugin.
  • Build/push gateway:0.1.0, cachectl:0.1.0.
  • Apply overlay via Flux; wait for gateway Ready.
  • Scale one model Deployment to 1 via /admin/hotload.
  • Run direct and routed smoke tests.

Day‑2 model add

  • Copy a vLLM manifest; change names/labels/model repo.
  • Add Service; start with replicas: 0.
  • Register in gateway LOCAL_MODELS (env JSON or code map).
  • Optionally weight it in routing CM.
  • Hot‑load and test.

Incident

  • If GPU errors mention FlashInfer: ensure VLLM_USE_FLASHINFER=0.
  • If crash mentions VLLM_PORT tcp://…: ensure enableServiceLinks:false and override env.
  • If downloads fail: confirm DNS/egress policies.

Here’s the drop-in gateway/app.py that adds routed mode and uses in-cluster RBAC to scale per-model Deployments (0↔1) for hot-load/unload. It keeps your OpenAI/Gemini support, lists models, and probes readiness.

# gateway/app.py
import os, json, time, random, asyncio
from typing import List, Optional, Dict, Any, Tuple
from fastapi import FastAPI, HTTPException, Body
from pydantic import BaseModel
import httpx

# --- Optional external providers (disabled when no keys)
OPENAI_API_KEY = os.getenv("OPENAI_API_KEY", "")
GEMINI_API_KEY = os.getenv("GEMINI_API_KEY", "")

use_openai = False
use_gemini = False
if OPENAI_API_KEY:
    try:
        from openai import OpenAI
        openai_client = OpenAI(api_key=OPENAI_API_KEY)
        use_openai = True
    except Exception:
        pass
if GEMINI_API_KEY:
    try:
        import google.generativeai as genai
        genai.configure(api_key=GEMINI_API_KEY)
        use_gemini = True
    except Exception:
        pass

# --- Local model registry (per-model services) -------------------------------
# repo_id  -> K8s Deployment name (to scale) and Service base URL (to call)
MODEL_REGISTRY: Dict[str, Dict[str, str]] = {
    "zai-org/glm-edge-1.5b-chat": {
        "deployment": "vllm-glm-edge-1p5b",
        "base": "http://vllm-glm-edge-1p5b.ai.svc.cluster.local:8000",
    },
    "zai-org/glm-edge-4b-chat": {
        "deployment": "vllm-glm-edge-4b",
        "base": "http://vllm-glm-edge-4b.ai.svc.cluster.local:8000",
    },
    "zai-org/GLM-4.5-Air": {
        "deployment": "vllm-glm-45-air",
        "base": "http://vllm-glm-45-air.ai.svc.cluster.local:8000",
    },
}
ALLOW_MODELS = list(MODEL_REGISTRY.keys())
AI_NAMESPACE = os.getenv("AI_NAMESPACE", "ai")

# --- Routing policy -----------------------------------------------------------
# Loaded once at startup from a mounted ConfigMap (k8s/base/config-routing.yaml)
ROUTING_PATH = os.getenv("ROUTING_PATH", "/config/routing.yaml")

def _load_routing_policy() -> Dict[str, Any]:
    import yaml
    try:
        with open(ROUTING_PATH, "r") as f:
            doc = yaml.safe_load(f) or {}
    except FileNotFoundError:
        # sane default
        doc = {
            "default": {"chat": [{"model": f"local:{ALLOW_MODELS[0]}", "weight": 100}]},
            "thresholds": {"escalate_on_confidence_below": 0.6, "max_output_tokens": 1024},
        }
    return doc

ROUTING = _load_routing_policy()

# --- K8s in-cluster client (for scaling) -------------------------------------
from kubernetes import client, config
try:
    config.load_incluster_config()
    apps_api = client.AppsV1Api()
except Exception as e:
    apps_api = None  # running locally without k8s; admin actions will 501

async def _http_get(url: str, timeout_s: int = 5) -> httpx.Response:
    async with httpx.AsyncClient(timeout=timeout_s) as cx:
        return await cx.get(url)

async def _service_ready(base: str, deadline_s: int = 120) -> bool:
    """
    Consider the backend ready when /v1/models or /health returns 200.
    """
    start = time.time()
    paths = ["/v1/models", "/health", "/healthz"]
    while time.time() - start < deadline_s:
        for p in paths:
            try:
                r = await _http_get(f"{base}{p}", timeout_s=3)
                if r.status_code == 200:
                    return True
            except Exception:
                pass
        await asyncio.sleep(2)
    return False

def _scale_deployment(name: str, replicas: int) -> None:
    if apps_api is None:
        raise HTTPException(501, "Kubernetes client is not available in this runtime")
    body = {"spec": {"replicas": replicas}}
    apps_api.patch_namespaced_deployment_scale(
        name=name, namespace=AI_NAMESPACE, body=body
    )

async def _ensure_hotloaded(repo_id: str, wait_ready_s: int = 180) -> str:
    """
    Scale the model's Deployment to 1 and wait for Service readiness.
    Returns the base URL for the model.
    """
    if repo_id not in MODEL_REGISTRY:
        raise HTTPException(400, f"model not allowed: {repo_id}")
    info = MODEL_REGISTRY[repo_id]
    # Scale up
    try:
        _scale_deployment(info["deployment"], 1)
    except HTTPException:
        raise
    except Exception as e:
        raise HTTPException(500, f"failed to scale {info['deployment']}: {e}")
    # Wait for the service to come alive
    ok = await _service_ready(info["base"], deadline_s=wait_ready_s)
    if not ok:
        raise HTTPException(504, f"model {repo_id} did not become Ready in time")
    return info["base"]

def _unload(repo_id: str) -> None:
    if repo_id not in MODEL_REGISTRY:
        raise HTTPException(400, f"model not allowed: {repo_id}")
    info = MODEL_REGISTRY[repo_id]
    try:
        _scale_deployment(info["deployment"], 0)
    except Exception as e:
        raise HTTPException(500, f"failed to scale down {info['deployment']}: {e}")

# --- FastAPI shapes -----------------------------------------------------------
app = FastAPI(title="AI Gateway", version="0.3.0")

class ChatMessage(BaseModel):
    role: str
    content: str

class ChatRequest(BaseModel):
    model: Optional[str] = None     # "local:<repo_id>" | "openai:<model>" | "gemini:<model>"
    task: Optional[str] = "chat"    # routed mode uses this (e.g., "chat", "classify")
    messages: List[ChatMessage]
    temperature: Optional[float] = 0.7
    max_tokens: Optional[int] = 512
    stream: Optional[bool] = False

class HotloadReq(BaseModel):
    model: str  # e.g., "local:zai-org/glm-edge-4b-chat"

# --- Helpers ------------------------------------------------------------------
def _choose_routed_model(task: str) -> str:
    """
    Choose from ROUTING[<scope>][task] with weights; for now scope="default".
    Returns a provider-qualified model string, e.g., "local:zai-org/glm-edge-4b-chat".
    """
    scope = "default"
    entry = ((ROUTING or {}).get(scope) or {}).get(task)
    if not entry:
        raise HTTPException(400, f"no routing policy for task={task!r}")

    # normalize weights
    total = sum(max(0, int(item.get("weight", 0))) for item in entry)
    if total <= 0:
        raise HTTPException(500, f"invalid routing weights for task={task!r}")
    pick = random.randint(1, total)
    cum = 0
    for item in entry:
        cum += max(0, int(item.get("weight", 0)))
        if pick <= cum:
            model = item.get("model")
            if not model:
                raise HTTPException(500, "route item missing 'model'")
            return model
    # fallback (shouldn't happen)
    return entry[-1]["model"]

async def _forward_local(base: str, req: ChatRequest, served_name: str) -> Dict[str, Any]:
    payload = req.model_dump()
    payload["model"] = served_name
    async with httpx.AsyncClient(timeout=600) as cx:
        r = await cx.post(f"{base}/v1/chat/completions", json=payload)
        if r.status_code >= 400:
            raise HTTPException(r.status_code, r.text)
        return r.json()

@app.post("/v1/chat/completions")
async def chat(req: ChatRequest = Body(...)):
    """
    - Direct mode: req.model provided (local:/openai:/gemini:)
    - Routed mode: req.model omitted → choose via ROUTING on req.task
    """
    provider: str
    name: str

    if req.model:
        provider, name = req.model.split(":", 1) if ":" in req.model else ("local", req.model)
    else:
        routed = _choose_routed_model(req.task or "chat")
        provider, name = routed.split(":", 1) if ":" in routed else ("local", routed)

    if provider == "local":
        # Scale to 1 if needed and wait for readiness
        base = await _ensure_hotloaded(name)
        # vLLM expects either repo id or served name; we forward the repo id
        return await _forward_local(base, req, name)

    elif provider == "openai":
        if not use_openai:
            raise HTTPException(501, "OpenAI disabled (no API key configured)")
        resp = openai_client.chat.completions.create(
            model=name,
            messages=[m.model_dump() for m in req.messages],
            temperature=req.temperature,
            max_tokens=req.max_tokens,
            stream=req.stream,
        )
        return resp.model_dump()

    elif provider == "gemini":
        if not use_gemini:
            raise HTTPException(501, "Gemini disabled (no API key configured)")
        import google.generativeai as genai
        model = genai.GenerativeModel(name)
        prompt = "\n".join([f"{m.role}: {m.content}" for m in req.messages])
        out = model.generate_content(
            prompt,
            generation_config={"temperature": req.temperature, "max_output_tokens": req.max_tokens},
        )
        text = out.text or ""
        return {
            "id": "chatcmpl_gemini",
            "object": "chat.completion",
            "model": f"gemini:{name}",
            "choices": [{"index": 0, "message": {"role": "assistant", "content": text}, "finish_reason": "stop"}],
        }

    else:
        raise HTTPException(400, f"unknown provider {provider}")

TGI Plan – GLM‑4.5‑Air (NF4) on RTX 8000

This doc breaks out the Text Generation Inference (TGI) path as a standalone deployment track for zai-org/GLM-4.5-Air using bitsandbytes NF4 quantization. The goals are (1) single‑GPU operability on Quadro RTX 8000 (cc 7.5), (2) leverage abundant host RAM for offload, (3) keep the OpenAI-compatible surface so the existing gateway stays minimal.

1) Why TGI for this track?

  • VRAM pressure: vLLM FP16 runs out of memory on 1× RTX 8000 during expert instantiation (MoE). NF4 reduces memory footprint significantly.
  • CPU RAM offload: TGI with bitsandbytes handles spillover gracefully; your host has ~250 GiB RAM.
  • OpenAI compat: TGI 2.x supports /v1/chat/completions with ENABLE_OPENAI_COMPAT=1, so the gateway can forward unchanged.

Trade‑offs: Higher latency than vLLM, but reliable “B” track that fits the card and can serve batch‑1 to modest QPS.

5) Tuning knobs

  • Quantization: Keep --quantize=bitsandbytes-nf4 for max VRAM savings. Alternatives if needed:

    • bitsandbytes-int8 (slightly more VRAM, faster than NF4 in some ops)
    • awq / gptq / exl2 (require different images/pipelines; not drop‑in)

  • Batch / tokens:

    • Shrink --max-total-tokens if VRAM is tight during traffic spikes.
    • Use smaller max_tokens in requests to limit decode working set.

  • CPU offload pressure:

    • Raise container memory limit if you see OOM‑killer on host side or swap churn.
    • Pin pod to a node with fast NVMe for HF cache.

  • Throughput controls:

    • NUM_SHARD=1 default is fine; keep batch sizes low to minimize latency.

B) Faster model downloads / cache

Right now your logs show ~1 file/minute for those big shards—this screams storage and/or single-stream limits, not gateway. Here’s how to speed that up:

  1. Enable HF Transfer on vLLM too (it’s only on TGI now):
env:
  - name: HUGGING_FACE_HUB_TOKEN
    valueFrom: { secretKeyRef: { name: hf-token, key: HUGGING_FACE_HUB_TOKEN, optional: true } }

  • Best: move model cache to a local NVMe via a local-path/local-storage class or a hostPath on that node. Example swap in vLLM/TGI:

    volumes:

    hostPath: { path: /var/lib/ai/hf-cache, type: DirectoryOrCreate }

    (Do this only if you’re okay pinning the workload to that node; add a nodeSelector you already have.)

  • Alternative: keep the PVC but ensure the storage class is backed by the node’s real disk (not loop), and mount with noatime.

  1. Warm the cache before the server starts Add an initContainer to prefetch with parallelism (faster than single-thread HF client):

  - name: prefetch
    image: ghcr.io/huggingface/hf-transfer:latest

      - name: HF_HUB_ENABLE_HF_TRANSFER

      - name: HUGGING_FACE_HUB_TOKEN

      - { name: hf-cache, mountPath: /models }   # match your container path
