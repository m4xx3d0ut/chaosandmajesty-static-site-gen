PXE Boot Server

iVentoy (easy way)

  • Project page: https://www.iventoy.com/en/index.html
  • Default install location: ~/.local/share/iventoy/iventoy-1.0.19

Launch iVentoy, drop ISO images into its data directory, and the PXE service will advertise them automatically to network clients.
